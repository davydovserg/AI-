# AI-пульт собственника: демо этапа 1 (90 дней)

Интерактивная демонстрация работы AI-пульта для группы компаний. Сделано на HTML, CSS и JS без зависимостей.

В шапке переключаются четыре эпохи: **М0 → М1 → М2 → М3** (дни 0, 30, 60, 90). Видно, как система подключается и какой эффект дают решения собственника.

## Что внутри

| Вкладка | Что показывает |
|---|---|
| **Пульт** | Брифинг «что требует внимания», Telegram-бот, 11 KPI с целями, платёжный календарь на 13 недель, риск-радар |
| **Решения** | Советы пульта по стандарту «сигнал → расчёт → варианты → рекомендация → уверенность». Кнопки «Да / Отложить / Нет» **меняют показатели следующих месяцев** |
| **Как работает система** | Анимированная схема потоков: 1С, Bitrix24, реестры → хранилище → ИИ-слой → собственник |
| **Группа** | 11 юрлиц по направлениям с открытыми данными и уровнем подключения к пульту |
| **Проект 90 дней** | Фазы, задачи руководителя (Р) и технического ассистента (Т), три контрольные точки с критериями, TOP-20 кейсов, журнал качества ИИ |
| **Эффект** | Динамика KPI по эпохам и таблица «до/после» |

## Данные

- `data/month-0.json` … `data/month-3.json` — состояние системы в каждой эпохе.
- `data/epochs.js` — те же данные одним файлом. Нужен, чтобы `index.html` открывался прямо с диска, где `fetch` недоступен.
- `tools/build-data.mjs` — генератор JSON: `node tools/build-data.mjs .`

Структура группы, выручка, число контрактов и судов взяты из открытых реестров (ЕГРЮЛ, ФНС, ЕИС, КАД, ФССП). Значения с меткой **«модель»** — расчётные, для демонстрации. Перед использованием их нужно сверить с 1С.

## Запуск

- Открыть `index.html` в браузере, или
- `python -m http.server 8000` и перейти на http://localhost:8000, или
- включить GitHub Pages (Settings → Pages → ветка `main`).

Вход по демо-паролю. Это **псевдо-защита** от случайного просмотра, а не безопасность: проверка идёт в браузере, код открыт. Не размещайте здесь реальные данные компаний.

Горячие клавиши: ← / → переключают эпохи.
